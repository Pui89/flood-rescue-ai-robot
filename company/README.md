# PUI89 AI Robotics company page

Static company landing page: [index.html](index.html).

## Preview locally

From the repository root:

    python -m http.server 8000

Open http://localhost:8000/company/.

## GitHub Pages

This page is intended to publish at:

https://pui89.github.io/flood-rescue-ai-robot/company/

The repository's Pages workflow now includes changes under `company/**`. The URL becomes available only after the changes are merged into `main`, GitHub Pages is configured to use GitHub Actions, and deployment succeeds.

The page describes PUI89 AI Robotics as a project/brand and does not imply that a legal company has been incorporated.
